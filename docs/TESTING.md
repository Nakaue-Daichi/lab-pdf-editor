# 手動テスト手順と実施記録

自動テスト（`npm test`）が固定しているのはロジックと注釈の往復。ここにあるのは **ブラウザと外部ビューアで人が確かめる項目**。
リリース前と PDF.js の更新後に一通り回し、末尾の記録に追記する。

## 手順（`npm run dev` → http://localhost:5173/lab-pdf-editor/ ）

取り込みの確認には `docs/fixtures/` の PDF を使う: `sample_hirata.pdf`（サンプルに「平田」のハイライトと Ink 注釈を足したもの）、`two_pages.pdf`（ページ数の違う PDF）。

| # | 操作 | 期待 |
|---|---|---|
| 1 | 「サンプルで試す」 | 3 ページが表示される。3 ページ目は横置き |
| 2 | 著者名を入れる | 以後のコメントにその名前が付く。リロードしても残る |
| 3 | 1 ページ目の文を選ぶ → 「＋ コメント」→ 本文を入力 | 選んだ範囲に著者色のハイライト。右にカード（引用・本文・時刻） |
| 4 | カードの返信欄に入力して Enter／「返信」 | 返信が付く。IME 変換中の Enter では送られない |
| 5 | 「付箋」（または `N`）→ ページの空白をクリック → 本文を入力 | 付箋アイコンとカード。付箋モードは自動で解除される |
| 6 | 3 ページ目（回転ページ）で文を選んでコメント | ハイライトが文字にぴったり乗る（ずれない） |
| 7 | 表示倍率を 150% → 幅に合わせる | ハイライトと付箋が文字に追従する |
| 8 | カードをクリック／本文のハイライトをクリック | 互いに選択・スクロールが連動する |
| 9 | `⌘S`（保存） | `sample_reviewed.pdf` が保存され、件数付きの通知が出る |
| 10 | 保存した PDF を「PDF を開く」で開く | コメント・返信・著者・色・位置が復元される。復元の通知は出ない（下書きではなく PDF から） |
| 11 | リロード → サンプルを開く（保存前に下書きがある状態で） | 「前回の下書きから N 件を復元」と出て、コメントが戻る |
| 12 | 別の人が付けた注釈入り PDF を「コメントを取り込む」 | 追加件数・既存件数の通知。著者チップが出て表示切替できる。同じ PDF をもう一度取り込むと追加 0 |
| 13 | ページ数の違う PDF を取り込む | 「ページ数が違います」の赤い通知。コメントは変わらない |
| 14 | 手描き（Ink）などを含む PDF を開く | 「表示しない注釈が N 件」の通知。保存しても消えない |
| 15 | 「Markdown ▾」→ コピー／保存（幅 1,439px 以下では「…」の中） | ページ順に著者・引用・本文・返信。件数と著者の行がある |
| 16 | コメントを削除／返信を削除 | 本文が空なら確認なしで消える。本文があれば確認ダイアログ |
| 17 | パスワード付き PDF を開く | 「パスワード付き PDF は開けません」の通知 |
| 18 | コメントを作る → 本文を入力 → 本文の外をクリック → `⌘Z` | 入力した本文がまとめて空に戻る。もう一度で コメント自体が消える。`⇧⌘Z`（または `Ctrl+Y`）で戻る |
| 19 | 削除・返信・取り込みの直後に `⌘Z` | 消したコメント（選択状態も）・返信・取り込んだコメントが戻る |
| 20 | 入力欄にカーソルを置いたまま `⌘Z` | その欄の文字だけが戻り、フォーカスは外れない（一覧は作り直されない） |
| 21 | 6 手以上操作してから `⌘Z` を連打 | 5 手戻ったところで「これ以上戻せません」の通知。ツールバーの ↶ も押せなくなる |
| 22 | 取り消した後に別の操作をする | ツールバーの ↷（やり直す）が押せなくなる |

## スマホ・タブレット（実機: iPhone の Safari・Android の Chrome・iPad の Safari）

画面の幅が 767px 以下（と横向きのスマホ）ではスマホ用の画面になる。ブラウザの開発者ツールのモバイル表示でも並びは確かめられるが、**長押しの選択・キーボード・共有シートは実機でしか出ない**ので、#S3・#S5・#S9 は実機で確かめる。

| # | 操作 | 期待 |
|---|---|---|
| S1 | スマホで開く → 「サンプルで試す」 | 上にファイル名と「…」、下に「戻す・やり直す・付箋・コメント・保存」。ページは画面の幅いっぱい（3 ページ目の横置きも幅いっぱい）。横スクロールが出ない |
| S2 | 2 本指で広げる → つまむ | 指の間の場所を保ったまま拡大・縮小し、離すとくっきり描き直される。ページ全体（上下のバー）は拡大されない。「…」→「幅に合わせる」で戻る |
| S3 | 文字を長押し → つまみで範囲を調整 | 指を止めて少しすると、下部バーが「解除／＋ コメント」に変わる。OS の選択メニュー（コピー等）と重ならない |
| S4 | 「＋ コメント」 | ハイライトができ、一覧が全高で開き、入力欄にキーボードが出る。入力欄がキーボードに隠れない |
| S5 | 書いてキーボードの「完了」（または本文をタップ） | 一覧が元の段（閉じていたなら閉じる）に戻る。何も書かずに閉じたら「ハイライトだけ残しました［取り消す］」 |
| S6 | 一覧を開いたまま下の「付箋」→ 余白をタップ | 一覧が閉じて「付箋を置く場所をタップ」の帯が出る。タップした所に付箋ができ、入力欄が開く |
| S7 | 下の「コメント」→ 取っ手を上下にドラッグ／タップ | 半分・全体・閉じるに吸い付く。速く払うと払った向きの段へ。カードをタップすると本文がその場所へ送られ、シートに隠れない |
| S8 | 本文のハイライト（細い行）や付箋をタップ | 少し外しても拾い、一覧が半分で開いてそのカードが選ばれる。‹ › で前後のコメントへ |
| S9 | 下の「保存」 | 共有シートが開き、「ファイルに保存」や Slack へ `元の名前_reviewed.pdf` を渡せる。閉じた（キャンセル）ときは下書きが残る |
| S10 | 長い PDF（修論など 80 ページ以上）を最後までスクロール → 先頭へ戻る | タブが落ちない。戻ったページは描き直される |
| S11 | iPad（縦・横）で文字を指で選ぶ／マウス・トラックパッドで選ぶ | 指のときは「＋ コメント」が本文の下端中央、マウスのときは選択のそば。右サイドバーのまま |
| S12 | パソコンで画面の幅を 1,920 → 1,280 → 768px と狭める。iPad（縦 768〜834px・横 1,024〜1,180px）でも | ツールバーが欠けず、あふれた操作は「…」に入る（iPad の縦では著者名も「…」へ）。「Markdown ▾」「…」のメニューが押せる |
| S13 | 著者名が未設定のまま初めてコメント（スマホは「＋ コメント」） | アプリのダイアログで著者名を尋ねる。「決定」でそのままコメントができ、入力欄にキーボードが出る |

## 外部ビューアでの互換確認（保存した PDF を開く）

| ビューア | 見えるべきもの |
|---|---|
| macOS プレビュー | ハイライトの色・付箋アイコン・ノート本文・著者名。**外観ストリーム無しの Highlight を描かない場合は Issue にして外観生成を検討する** |
| Acrobat Reader | 注釈一覧にコメント・返信・著者・日時。ハイライト位置 |
| Zotero（PDF リーダー） | 注釈として取り込まれ、著者名が残る |
